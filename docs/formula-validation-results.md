# 公式验证结果与主线更新

本轮按docs/formula_validation.md固定协议执行30项真实数据实验、180项已知答案设置；所有0..20/21阶训练内选阶完整。计算仅使用训练响应；保存每次划分、方程、逐交易预测和组均指标。原始公式、分档和全部旧分析保留。

主结果：主样本固定留出960笔，对74个合格单字段组（20个分区、每组测试n≥30）一阶r=0.773729、预测R²=0.508423、RMSE=1.365333pp；原无正则三阶R²=-0.424697。固定三阶与一阶均预先规定，不把测试中较好者宣称为已独立确认的最终模型。训练内选阶的三个结果k=8/17/1，对应R²约0.187/0.162/0.508，说明选阶具有敏感性。

主样本全部已有组重算测试成员，去除精确重复测试成员后n≥30有132602组。一阶r=0.750275、R²=0.376461、RMSE=2.483021pp；三阶R²=-0.261004。这是与单字段不同的目标组族，不能合并口径。正车库样本一般更弱且与主样本重叠，未证明车库条件增加解释力。

完整剖面、空间、内部时间留出已单独执行；原三阶在两样本各迁移测试的预测R²均为负。训练内选阶在主样本这三个划分分别为20阶，对应R²约0.412/0.183/0.298；这是当前算法的回顾性范围，不是政府模型改进或因果归因。

已知答案：8二值字段256状态、无噪声四阶函数。205个训练状态对51个未见状态，四阶真值RMSE约4.3e-13pp，三阶约10.664pp，八阶约4.505pp；加入4pp独立噪声后，四阶未见状态真值RMSE约4.039pp。表示空间、支持可辨识性和噪声稳定性必须分别评价。

下一步研究决定：保留原核及任意组合能力，比较明确的谱收缩/正则化与更稳定的训练内选阶。核心问题是联合项相对单项能否带来可重复增益；不根据训练内精确拟合追求复杂度。新的模型修改仍属内部探索；更强确认需要兼容新时期数据。
