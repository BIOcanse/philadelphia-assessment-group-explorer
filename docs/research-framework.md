# 组合偏差研究：目标、证据与下一阶段

## 本轮任务与决定

用户要求独立总结既有工作，整改研究与介绍主线，以已有材料进行高层判断。研究问题按最新方向定义：能否从房屋及环境条件的组合中，推导出可解释、可验证的组均成交／估值规律？原始公平性问题是现实动机；组合发现、数学表达、推导方法验证、机制与应用是连续但不能互相代替的证据阶段。

本轮整理和整改介绍，不把未经设计的新实验、其他模型的成绩或训练内还原写成公式泛化结果。既有分析全部保留。使用同一canonical HTML报告管线，生成新的主线页并沿用两版同一入口。

## 实际已经完成

1. 数据基础：正常交易清洗、历史属性/学校/警情/就业等补充、来源和时间审计、价格相关可得性检查。
2. 组合发现：任意大小条件表达的组均值枚举、相同成员去重、全量排序、边缘组和直方图、大组与重叠检查。
3. 组合比较：统一水平校准、条件放宽和共同支持标准化、四格非加性线索、部分空间/时间内部诊断。
4. 数学表达：稀疏count/sum充分统计、等价选择算子、任意阶类别核、加权投影与逐组还原验证。低阶满秩仍有3310/1449个系数；未完成小参数规律提取。
5. 配套设施：编号和双语释义、工作台、矩阵/投影、两版分发与可复算记录。这提高可理解性和复查效率，本身不是新研究发现。

当前最强结论是：已记录数据存在可定位的组均差异，并具有可精确还原的有限样本表示。当前不能声称核推导方法已具有训练外准确性、三阶就是现实最高交互阶数、已查明具体因果来源或已改进政府模型。

## 四个研究问题

| 问题 | 已有证据 | 下一步判据 |
|---|---|---|
| 哪些组合有系统性差异？ | 全组均值与支持、共同偏移和条件比较 | 冻结发现规则后，在留出记录上检查组差异是否延续 |
| 如何把巨大组合空间写成方程？ | count/sum等价、核与显式空间一致、全组还原 | 保留证明与数值检查，区分低阶和少参数 |
| 推导出的方程能学习可重复规律吗？ | 尚无该方程的训练外成绩 | 小样本重新推导→留出组均值；学习曲线、简单基准、未见组合与地区/时间检查 |
| 规律能解释和改善估价吗？ | 条件关联与其他校准模型仅作对照 | 在验证过的公式上检查稳定组效应、残差与组层校准收益 |

## 现有数据能立即支持的下一阶段（按优先级）

1. **公式验证**：以训练数据重新完成剖面、核、系数和选择步骤，在未参与推导的数据上评价组均预测；r、预测R²和百分点误差同属此对象。比较常数、单项和更高阶方法，绘制训练量—准确性—复杂度关系。固定测试集，训练量逐步增加；全体结果单列为重建诊断。
2. **方法辨别力与稳定性**：利用已存在的四阶奇偶反例，扩展已知答案的函数、稀疏支持与噪声实验；检查在重抽样或地区/时期改变后，预测函数是否稳定。只在可辨识条件下谈真实阶数恢复；不靠任意基下系数逐项相同判断稳定。
3. **可靠的简化**：在验证准确性基本保留的前提下减少参数和条件，形成可读的代表性效应与异常组；条件重叠和同一批成员不重复算作独立发现。具体误差容许值应由验证曲线支持，不凭直觉承诺。
4. **回到现实用途**：用验证过的公式解释哪些组仍被遗漏，并检查校准是否改善目标组且不恶化其他组。现有其他模型可作为基准；成绩始终保留模型名、目标和验证样本。

现有2017数据可做内部记录/完整剖面/空间/时间留出；这些记录与分档已被研究过，不等于全新盲测。其他年份的清洗交易虽在，历史条件和分母口径尚未齐备，不能直接宣称跨年验证已具备。新城市或新年度验证排在内部方法验收之后。当前无需先扩大抓取。

## 介绍页结构与交付

读者按“要回答什么→我们做了什么→现在知道什么→公式做到哪一步→接下来怎样验证→结论与用途”阅读。状态与证据相邻，数字只支持主张。沿用技术报告格式，但高层正文不塞实现参数。

- `scripts/build_research_overview.py`只读已有结果，输出`outputs/research_overview/artifact.json`、主线Markdown、成果表和来源哈希。
- `scripts/deliver_report.mjs`生成`outputs/research_overview/research-story.html`。
- `scripts/package_research_story.py`支持明确输入目录，将已验收报告和证据ZIP接入两版共享静态目录。
- 旧`outputs/research_story/`、各原始分析及v1.2.0 Release保留；新主线不把旧R²当作公式验证。

验收：主张逐项对应现有源文件；旧输入哈希保持；无虚构训练外成绩；阅读与链接验证通过；两版包含同一页面。
