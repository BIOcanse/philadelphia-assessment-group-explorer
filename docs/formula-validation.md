# 核公式推导方法的训练外验证 / Formula validation

## 问题与固定范围

本轮承接研究框架，实际检验我们已有的类别条件核：从部分交易重新推导方程，能否预测未参与推导成员的组均成交／原估值比率？不使用其他预测模型成绩作替代。原始输入、旧代数分析和组目录均保持。

主/正车库样本4903/2148笔、20/21字段。输入不含成交金额或估值派生字段；字典使用全源特征分布、部分属性时点未认证、分母年份和上游选择仍有限制。本实验是已有资料上的内部、回顾性方法验证，不能称为新盲测或事前估价能力。两样本重叠，不把跨样本差异当增加车库的收益。

## 推导与选阶合同

只在每次实际训练记录内合并完整剖面，计算n、s、μ。K_k(x,u)=Σ(t=0..k)C(h(x,u),t)/Σ(t=0..k)C(d,t)，h为相同字段数。对sqrt(n) K sqrt(n)作原有加权特征分解，保留大于最大特征值1e-10的方向，求原无正则最小范数方程mhat=μ+Σα_u K_k(x,x_u)。测试数据只作核求值，不进入任何响应统计或参数。

检查k=0..d全部阶数。训练满秩后仍继续：不同核在未见剖面上的延拓可以不同。选阶在外层训练集内部预留25%记录；以预设单字段分区的组均平方误差选最小损失阶数，数值并列取较低阶；之后在完整外层训练子样本重拟合。正则化不是本轮原公式的隐含改动。

## 实验设计（结果产生前固定）

1. 学习曲线：沿用既有development/test划分（主3943/960、车库1717/431），外层测试成员固定。使用10%、25%、50%、100%的development记录；三个固定随机种子20260908、20260909、20260910产生嵌套训练顺序和内部选阶。并列报告训练均值、固定单项k1、原精确表达阶数k3和训练内选阶。三次结果是训练/选阶敏感性范围，不作为三个独立外部重复。
2. 内部迁移：用种子20260908另固定完整剖面分组留出20%、2017成交日最后20%记录、1km空间网格分组留出20%网格。仅使用训练分区完成内部选阶，另列空间/时间交叉支持。各检验单独报告，不把其中最好的一项代表全部范围。
3. 所有实际组诊断：对主学习曲线第一种子、100%development模型，流式评价全部已有canonical组的测试成员。按测试n≥1/10/30/100/300汇总；空测试组单列。继承的不同完整样本组可能在测试集拥有相同成员，去重后的测试成员组另算；重叠不是独立重复，目录扫描仅作辅助诊断。
4. 已知答案：8个二值字段的完整256状态，预设单项、两项、四项、八项奇偶、纯噪声函数；每个状态4个训练噪声重复与4个独立测试重复，噪声0与4个百分点。分别检查完整支持的新交易和20%未见状态。检查所有k0..8；未见状态的恢复取决于可辨识性，不承诺任意高阶缺角恢复。

## 组单位与统计量

原始q_i=成交/原估值；测试组实际y_G=mean(q_i)，预测p_G=mean(mhat_i)，必须使用相同测试成员。主评价为预设各单字段的互斥类别分区；每个分区内合格组等权，各分区权重相同。固定全部字段的两两分区作为更细诊断，按阶数分别展示，不从测试响应挑选组合。测试最小支持30笔为主，10/100笔为规模敏感性；内部选阶最小支持5笔。少于2个合格类别的分区不参与跨组评分，数量和覆盖记录保留。

跨分区分数是固定诊断汇总，仍反复使用同批交易。权重w_G在每分区内和为1，再除有效分区数。r为相同权重下的Pearson相关；预测R²=1−Σw(p−y)²/Σw(y−weighted_mean(y))²；基准改善=1−Σw(p−y)²/Σw(μ_train−y)²；RMSE/MAE换算为百分点。R²可以负，r²不代替R²；常数预测r未定义，分母无变化时指标为空。另保存逐分区分数及交易层辅助误差。预设分区的同成员重复组不作为独立样本或显著性分母。

## 文件与执行

- scripts/formula_validation.py：已有核的训练/求值、固定划分、组层计分、真实与已知答案实验；输出outputs/formula_validation/的配置、训练选择轨迹、逐组/逐交易预测、方程和统计。
- scripts/scan_formula_groups.cpp：只读原canonical目录，收缩测试成员的n、q和预测；输出全组诊断及支持充分的组值。
- scripts/validate_formula_validation.py：独立显式设计、SQL/标量组均与指标复算、训练测试隔离、保存方程复算和源哈希检查。
- 报告使用既有canonical artifact→deliver_report.mjs管线；主线保留此前研究背景，增加实际公式结果，更新两版共享research-story.html；原版本保留。

CPU沿用2个BLAS线程，主最大训练剖面小于原3310，旧3阶计算约18秒。本轮多次较小谱分解；先计时单个最大内部拟合，再据实测估算。进度每个拟合阶数/实验写日志，可按实验独立复跑；不重复海量组合枚举。需要的原目录扫描沿用原生C++方式。

验收：所有划分与输入哈希保存；全部选阶轨迹可查；主指标独立复算；明确未见条件与样本范围；已知函数真值与噪声分开；图表和结论只使用本轮实测；两版同页。报告结构覆盖技术摘要、定义、已有发现背景、真实组证据、推导/实验、已知答案、限制和下一步。
